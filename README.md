# Powderline

A small browser-playable downhill skiing arcade game inspired by the classic SkiFree. Dodge the trees, collect slalom gates, hop over trouble, and see how long you can stay ahead of the yeti.

## Play

Open `index.html` in a modern browser. There are no build steps, packages, or server dependencies.

## Controls

| Key | Action |
| --- | --- |
| ← / A, → / D | Steer |
| ↑ / W | Build speed |
| ↓ / S | Brake |
| Space | Jump |
| P / Esc | Pause or resume |
| Enter | Start or replay |

On touch screens, use the on-screen left, jump, and right buttons. The best distance is saved in local browser storage.
